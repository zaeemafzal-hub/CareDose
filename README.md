CareDose

Never miss a dose. CareDose is a lightweight, installable web app for tracking medicines and getting reminded when it's time to take them.

Features

Today view — this day's doses in order, with clear Upcoming / Due now / Taken / Missed states
Medicines — add, edit, and delete medicines with custom times, days of the week, dosage, notes, and a color tag
Skip & snooze — skip a dose on purpose, or snooze a reminder for 10 minutes
Missed-dose tracking — a dose left unmarked for 3 hours is automatically logged as missed
History — 7-day adherence percentage, a day-by-day dot overview, and a per-medicine taken/missed breakdown
Refill tracking — optionally track doses remaining per medicine, with a low-stock warning banner
Quiet hours — pause notifications overnight without turning reminders off entirely
Notifications — browser notifications while the app is open, plus optional email reminders via a connected EmailJS account
Backup & restore — export your data as a file and import it on another device
Installable — has a manifest and service worker so it can be added to a phone's home screen and opened offline
